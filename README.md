## 👨‍💻 About Me

I'm a software developer focused on **backend development, cloud infrastructure, and software architecture**.

I primarily work with **Java and Spring Boot**. I'm interested in how systems communicate, how software runs in production, and how good engineering decisions make applications more reliable and maintainable.

I enjoy building things from the ground up—whether that's a message broker, a Git platform, or a small tool that makes everyday work easier.

```text
  Backend            APIs, services, and business systems
  Infrastructure     Messaging, deployment, and observability
  Developer tools    Practical tools for everyday workflows
  Product building   From an idea to something people can use
```
